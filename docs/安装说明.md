# 安装说明（v0.12）

## 下载与包说明

由于搜狗输入法的候选窗底图是静态 PNG，引擎不支持把当前模式文字动态渲染到左上角名牌里，因此本项目按名牌标签提供了**三套皮肤包**（位于 `dist/` 与 `dist/v0.12/`）：

| 文件 | 名牌标签 | 体积 | 适用场景 |
| :--- | :--- | :--- | :--- |
| `aokana-zh.ssf` | **中文** | 57.0 KB | 推荐日常全拼中文输入使用 |
| `aokana-en.ssf` | **英文** | 57.4 KB | 英文标签变体 |
| `aokana-sp.ssf` | **双拼** | 57.4 KB | 推荐双拼输入用户使用 |

> 三套皮肤的状态栏均为可点击切换的「中 / 英」单球按钮，功能完全一致，仅左上角蓝色胶囊名牌烘焙文字不同。

## v0.12 核心特性

1. **0.85 倍紧凑比例**：H1 横排候选窗为 `714×151`（由 2× 母版 Lanczos 下采样 + UnsharpMask 锐化），V1 竖排为 `222×182`，字号 `17px`，在高分屏下大小适中。
2. **粗体与高对比选中色**：默认采用 Windows 自带 `微软雅黑 Bold` 粗体；首个候选词采用 `#2A93C6` 深天蓝，普通候选与拼音采用 `#6E6E6E` 正文灰。
3. **双分隔线对齐**：两条 `#8FD0E6` 青色细线精确包裹候选词行，拼音与候选词均不压线。
4. **单球状态栏 + 不透明白面板**：面板中心 100% 不透明，防止复杂壁纸干扰阅读；状态栏精简为 `56×56` 悬浮蓝球。

## 安装方法

### 方法一：双击直接安装（推荐）
1. 在 `dist/` 目录下找到需要安装的 `.ssf` 文件（例如 `aokana-zh.ssf`）。
2. 双击文件，在弹出的搜狗「安装皮肤」对话框中点击**确定**，皮肤会自动生效。
3. 如需切换其他变体，右键输入法状态栏 → **更换皮肤** → 选择「苍之彼方·四重奏（中文/英文/双拼）」。

### 方法二：通过命令行工具安装
```powershell
node tools/dsh-sogou-skin/src/cli.js install dist/aokana-zh.ssf
```

## 已知限制

- **V1 竖排分隔线**：V1 竖排底图的两条分隔线按行高烘焙在底图内，多行候选拉高窗口时可能压线（推荐使用 H1 横排单行模式）。
- **候选窗右侧按钮**：搜狗 16.x 引擎默认在候选窗右侧绘制展开候选（`▼`）与快捷菜单（`≡`）图标，属于引擎内置行为。
